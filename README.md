# Military Secure Communication

A secure communication web application designed to provide protected messaging using modern authentication and encryption techniques.

## Project Overview

The **Military Secure Communication** project focuses on secure communication between authenticated users. The application combines user authentication, encrypted messaging, and secure cloud-based data storage.

## Features

* 🔐 Firebase Email & Password Authentication
* 🛡️ Multi-Factor Authentication (MFA) demonstration
* 🔒 AES-GCM encryption for messages
* ☁️ Firebase Firestore for message storage
* 👤 User-specific message access
* 💬 Secure messaging interface
* 🔑 Authentication-based Firestore security rules

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Firebase Authentication
* Firebase Firestore
* AES-GCM Encryption
* Visual Studio Code

## Security

Messages are encrypted using **AES-GCM** before being stored in Firestore. Firestore security rules restrict access to authenticated users and user-specific messages.
